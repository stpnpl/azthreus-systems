## Shared style prompt

For each image, paste this block followed by **one** of the six product prompts below. The filenames are for saving the results.

Draw one hand-built 16-bit arcade inventory sprite for a deep-space engineering game. Compose it on a 64 × 64 logical pixel grid, then enlarge it to a 1024 × 1024 square PNG using crisp nearest-neighbor scaling. Use a genuinely transparent background with a clean alpha channel. Center the complete object with about 10% clear padding on each side. Make its silhouette recognizable at 48 × 48 pixels.

Use the Azthreus Systems palette: deep steel blue `#38506C` for structural metal, dark slate `#414C6B` for shadow planes, teal `#539394` for active components, warm sand `#ABA18C` and terracotta `#9C7A65` for physical materials, near-black for outlines, and white for a few hard highlights. Light the object from the upper left. Build it from a few large pixel clusters, with stepped diagonals and two or three flat tones per material. Give the exposed upper edges a light rim so the sprite reads on a dark website. Keep the exterior transparent, including gaps between parts. Omit lettering, numbers, logos, scenery, tile backgrounds, cast shadows, glow, gradients, and anti-aliasing.
